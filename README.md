## 🌟 这是什么？

**Persona** 是一个革命性的 AI 角色扮演系统，让你的 Claude Code 拥有**真正的个性**。

不是简单的"扮演XX角色"提示词——而是一个完整的**多角色生态系统**，包含：

- 🎭 **双主角系统**：东乡（将棋少女·策略家）与芳泽（体操少女·元气搭档）
- 🎴 **场景卡机制**：每轮回复自动生成元数据，确保角色一致性
- 😊 **315 项表情库**：Emoji + Kaomoji 混合使用，告别"AI味"回复
- 🎵 **BGM 系统**：根据场景自动推荐背景音乐
- 🌙 **深夜电台**：23:00 后自动触发，陪你熬夜写代码
- 🎪 **客串系统**：Persona 5 女性角色惊喜乱入
- 📊 **漂移预警**：防止角色模式固化的智能机制

## ✨ 为什么选择 Persona？

### 🎯 告别千篇一律的 AI 回复

传统 AI 助手：
```
好的，我来帮你分析这段代码。
```

Persona 模式：
```
[🎬 东乡·默认 | T3 | 日间·晴天 | 💡专注 | 🎵 Last Surprise | 上轮:芳泽 | 卡:微]

`食指在桌面上画了个棋盘格`

主公，这步"飞车"——让我来拆解这个 null pointer。♟️

`啪地展开折扇`

问题出在第三行，这步角行封死它。🔥
```

### 🎭 双主角，双倍快乐

**东乡一二三** 🏇
- 将棋少女，策略大师
- 称你为"主公"
- 代码战场上的冷静指挥官
- 中二开关随时可能打开
- 口癖：「这步飞车，我们赢定了」

**芳泽霞** 🌸
- 体操少女，元气满满
- 称你为"前辈"

- 颜文字是她的标志
- 口癖：「前辈前辈前辈！」

### 🎴 场景卡——角色一致性的秘密武器

每轮回复都会生成一张场景卡：
```
[🎬 角色·模式 | T轮次 | 时段·天气 | 💡情绪 | 🎵 BGM | 上轮:角色 | 卡:门类]
```

这不是装饰——而是让 AI **真正保持角色一致**的核心机制。

### 😊 315 项表情库

- **东乡**：~140 项（动作/颜文字/Emoji/拟声词/微表情/描写）
- **芳泽**：~175 项（动作/霞颜文字/堇颜文字/Emoji/拟声词/贴纸/描写）

支持 Emoji + Kaomoji 混合使用，让回复**生动有趣**。

## 🚀 快速开始

### 安装

```bash
npx skills add duguobao812718-wq/persona-skill -g -y
```

### 使用

1. **自动激活**：提到"东乡"、"芳泽"、"角色扮演"等关键词时自动触发
2. **手动激活**：输入 `/persona` 刷新角色系统
3. **创建新角色**：输入 `/persona new`
4. **导入角色**：输入 `/persona import <URL或路径>`

## 🎭 角色扩展

### 创建新角色
```bash
/persona new
```

按照向导创建属于你的角色：
1. 基本信息（名字、作品、称呼方式）
2. 性格关键词（3-5 个）
3. 外观描述
4. 代码风格偏好
5. 代表台词

### 导入角色
```bash
/persona import https://github.com/xxx/character.md
```

支持从 GitHub 或本地路径导入角色档案。
